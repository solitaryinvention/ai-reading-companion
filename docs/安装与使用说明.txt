AI 读书助手 0.5.1 · Windows x64

给好友的安装说明

1. 请在 Windows 电脑上下载并解压整个 ZIP。
2. 双击 AI读书助手 Setup 0.5.1.exe，按提示安装。
3. 打开软件，导入自己的 PDF 或 EPUB。
4. AI 功能需要自行连接账户，或填写自己的 DeepSeek API Key（独立计费）。
5. 阅读、OCR、PDF 转文字 EPUB 不需要 AI 账号。

新版功能：五档讲解详略、每本书独立 agent.md、长期思想档案、划线。
鼠标选文后可复制到聊天框或引用到聊天。每本书的对话独立保存。

此软件在 Windows 电脑运行，不是在手机微信内运行的小程序。
分享包不包含制作者的书籍、对话、登录信息或 Key。
安装包未做商业代码签名；请核对来源，不要关闭系统安全防护。
ChatGPT 连接是否可用取决于自己的账户授权与网络，未保证所有账户可用。

升级：先退出旧版，再安装；原数据仍在 %APPDATA%\reading-companion。
备份：退出软件后复制整个数据目录。
OCR 和 AI 内容可能有误，重要内容请对照原书。

文件：SHA256SUMS.txt 可用于核对安装程序完整性。
