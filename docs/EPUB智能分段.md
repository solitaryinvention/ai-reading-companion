# EPUB 智能分段（开发版）

设置中的“EPUB 自动智能分段”默认关闭，选项会持久保存。开启后分析当前 spine 文档；翻到其他章节时分析新章节。首次分析将当前章节发送给所连接的模型，会使用模型额度；仅接收段落编号边界，不采用模型改写的正文。

以2000–6000非空白字符为参考，优先保留话题、论证、例子与解释的完整性，允许超出参考范围；不能保证模型每次都选到最佳边界。标注显示竖线、段号、字数和复制按钮。点击复制整段，不自动发送。关闭会隐藏标记，已发起的请求可能继续完成并缓存结果，但不会重新显示标记。

按书籍和当前文字内容缓存有效边界，重启可复用，删除书籍时清理缓存。分析失败可关闭后重新开启重试。特殊文本布局无法完整映射、或单个文档超过40万字符时明确报错，不静默漏掉原文。PDF 不提供分段功能。

PDF 与 EPUB 选中正文后，按鼠标右键在鼠标旁显示“复制”菜单；左键选中不弹出，空选区不显示，点击正文或滚动后隐藏。原生 Ctrl+C 仍可用。

验证：`npm test` 与 `node tests/segments.mjs`。桌面测试使用独立数据和模拟模型响应，覆盖两段标记、复制、缓存、关闭恢复、PDF 无入口及两格式选文复制；不等于已完成真实模型语义质量评测。0.5.8修复版提供自动分段设置与右键复制。
